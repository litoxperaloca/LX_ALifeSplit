# Changelog

All notable changes to **LX A-Life Split-Screen Fix**.

## v1.1.0

First public release on the Steam Workshop and GitHub.

### Included

- NPCs perceive every local player
- Encounters, raids and world events reach everyone
- Player 2's emotes are player 2's
- The talk window opens where you are
- Reputation tab no longer traps the controller
- NPC aim resets between targets
